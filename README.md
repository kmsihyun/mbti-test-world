# MBTI TEST 세상

20개 질문으로 성향을 알아보고 로또 미니게임을 즐기는 정적 웹 프로젝트입니다.

## 프로젝트 이력

- 2023: 대학 수업 프로젝트로 제작. 개발은 김시현이 전체 구현했습니다.
- 2026.11.01: 기존 유형 설명과 이미지, 미니게임을 보존하고 성격 테스트를 복구했습니다.
- 사용 기술: HTML, CSS, JavaScript. 서버나 회원가입 없이 브라우저에서 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

## 복구한 내용

- 모바일 화면을 고려한 메인 및 설문 화면
- 20문항에 성향 축과 긍정 응답 방향을 명시한 채점
- 의미가 불명확했던 기존 문항을 성향 축에 맞는 문장으로 정비
- 진행률, 이전 질문으로 이동, 답변 수정, 다시하기
- 16개 유형 이미지 경로 및 유형 연결 수정
- 로또 기본 화면에서 누락된 결과 영역 복구
- 예전 설문 주소를 새 설문으로 연결

결과는 재미로 보는 성향 분류이며 정식 MBTI 검사나 심리 진단이 아닙니다. 과거 유형 설명과 이미지는 원본 자료로 보존하고, 현재 화면은 간결하게 새로 작성한 유형 소개를 사용합니다.

## 성격 도감과 결과 화면 고도화

- 결과의 **더 알아보기**에서 해당 유형의 상세 정보로 이동합니다.
- `explore.html`에서 16개 유형을 검색하거나 4개 그룹으로 필터링합니다.
- 유형별 특징, 키워드, 강점, 성장 힌트와 대화 방법을 제공합니다.
- E/I, S/N, T/F, J/P의 네 가지 관점을 설명합니다.
- 결과에 성향별 응답 분포를 표시합니다. 이 비율은 검사 정확도나 성격의 강도를 뜻하지 않습니다.
- 같은 탭에서 성격 도감을 둘러본 뒤 결과로 돌아올 수 있습니다. 결과는 브라우저 세션 저장소에만 보관하며 외부로 전송하지 않습니다.
- 결과 문구 복사를 지원합니다. 브라우저가 자동 복사를 지원하지 않으면 직접 복사할 문구를 보여줍니다.
- 휴대폰 화면과 키보드 탐색, 동작 줄이기 설정을 고려했습니다.

운영은 **비용이 발생하지 않는 방식만 사용**합니다. 유료 API나 서버 의존성은 추가하지 않았고, 이번 변경에는 배포 설정이 포함되지 않습니다. 상세 원칙은 `PROJECT_NOTES.md`를 참고하세요.

## 검증

Node.js 18 이상에서 `node --test quiz.test.cjs`를 실행합니다. 16개 결과 조합, 역방향 채점, 입력 검증, 이미지 존재 여부와 로또 결과 영역을 검사합니다.

## 파일

- `index.html`: 메인
- `survey.html`, `survey.js`: 설문 및 결과 화면
- `quiz.js`: 질문 및 채점
- `results.js`: 기존 유형 설명과 이미지 경로
- `types.js`: 현재 화면에서 사용하는 16개 유형과 성향 축 설명
- `explore.html`, `explore.js`: 성격 도감, 검색, 필터, 유형 상세
- `style.css`: 공통 반응형 스타일
- `로또페이지.html`, `lotto1.html`~`lotto3.html`: 기존 미니게임

원본은 Git 이력에 보존되어 있습니다. 미니게임 화면 전반의 디자인 및 기존 유형 설명의 편집은 이번 복구 범위에 포함하지 않았습니다.
